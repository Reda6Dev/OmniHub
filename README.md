# OmniHub v1.0 ⚡

> **A modern, config-driven desktop automation workbench & game development utility hub built with .NET 8 and WPF.**

---

## 🌟 Overview
**OmniHub** is an all-in-one developer workspace designed to eliminate repetitive CLI overhead. It consolidates daily compilation, modding, media asset preparation, and project maintenance tasks into a unified desktop experience.

### ✨ Key Features
- **Config-Driven Architecture:** Dynamically loads pipelines, tools, and categories from JSON specifications without modifying core binaries.
- **50+ Integrated Automation Tools:** Built-in suites for .NET compilation, Git synchronization, media conversion (multi-size ICO generation, OGG encoding), and game file management.
- **Online Cloud Catalog:** Discover, preview, and install community automation wings directly inside the app.
- **Windows 11 Fluent UI:** Polished dark mode interface with real-time terminal output logs, bilingual Arabic/English dynamic localization, and command search (`Ctrl + K`).
- **Zero-Dependency Portable Binary:** Built with self-contained single-file publishing—no external .NET runtimes required.

---

## 🚀 Quick Start
1. Download `OmniHub_v1.0.0_win-x64.zip` from the **Releases** section.
2. Extract the archive.
3. Run `OmniHub.UI.exe`.
